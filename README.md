# 🤖 Claude Code - Comandos, skills y agentes

![Docs: Claude Code](https://img.shields.io/badge/Docs-Claude_Code-D97757?style=for-the-badge&logo=anthropic&logoColor=white)

**Referencia en español, en formato de acordeón, de todos los comandos `/`, comandos y flags de terminal (`claude --…`) y subagentes de Claude Code, con su sintaxis exacta y ejemplos prácticos de uso.**

🔗 **([👉 Ver en: Claude Code - Comandos, skills y agentes](https://isabosdev.com/claude-code-comands-skills-agents/))**

-----

## 🚀 Características del proyecto

Una única página web, sin dependencias, pensada para consultar rápido qué hace cada comando, cuándo usarlo y cómo se escribe. Más de 250 entradas desplegables, ordenadas alfabéticamente dentro de cada categoría.

### 📚 Contenido

#### ⌨️ **Comandos dentro de la sesión (`/`)**

- 💬 **Sesión y conversación:** `/clear`, `/compact`, `/resume`, `/rewind`, `/fork`, `/goal`…
- 🧠 **Modelo y razonamiento:** `/model`, `/effort`, `/fast`, `/advisor`, `/autocompact`.
- 🔐 **Permisos y ajustes:** `/permissions`, `/sandbox`, `/update-config`, `/fewer-permission-prompts`.
- 🛠️ **Desarrollo y calidad:** `/code-review`, `/security-review`, `/simplify`, `/debug`, `/verify`.
- 🧩 **Extensiones:** `/agents`, `/skills`, `/mcp`, `/plugin`, `/reload-plugins`.
- 🎨 **Artifacts y diseño:** `/design`, `/slides`, `/dataviz`, `/artifacts`.
- 🔌 **Integraciones, cuenta y ayuda:** `/ide`, `/chrome`, `/install-github-app`, `/usage`, `/doctor`, `/help`.

#### 🖥️ **Comandos y flags de terminal (`claude …`)**

- 🏁 **Inicio y mantenimiento:** `claude -p`, `claude -c`, `claude -r`, `claude update`, `claude auth`, `claude mcp`…
- 🛰️ **Sesiones en segundo plano:** `claude agents`, `attach`, `logs`, `respawn`, `stop`, `daemon`.
- 🚩 **Flags `--`:** sesión, modelo y permisos, configuración y MCP, prompt del sistema, modo no interactivo y diagnóstico.

#### 🧑‍💻 **Subagentes**

- 🔎 **Agentes integrados:** `claude`, `claude-code-guide`, `Explore`, `general-purpose`, `Plan` y `statusline-setup`.

### 🧭 Cómo está organizada cada entrada

- 📖 **Qué es y qué hace:** descripción de su función.
- 🎯 **Para qué se usa:** el caso de uso típico.
- 🧾 **Sintaxis:** forma exacta de escribirlo (`<obligatorio>`, `[opcional]`, `a|b`).
- 💡 **Ejemplos:** lo que escribes y lo que ocurre, tanto en la sesión como en la terminal.

### 💻 Stack tecnológico

- **HTML5:** estructura semántica y acordeón nativo con `<details>`.
- **CSS3:** diseño responsive, variables CSS y tema claro/oscuro automático.
- **JavaScript (vanilla):** buscador en vivo, expandir/contraer todo y año dinámico en el pie.

### ▶️ Cómo usarlo

- 🖱️ Abre `index.html` en cualquier navegador; no requiere instalación ni servidor.
- 🔍 Usa el buscador para filtrar por comando, alias o palabra clave.
- 🗂️ Navega por categorías con los accesos directos de la parte superior.

### 🎯 Propósito

- 🎓 **Quienes empiezan con Claude Code:** una guía clara en español de lo que hay disponible.
- 👩‍💻 **Desarrolladores habituales:** consulta rápida de la sintaxis y de los flags menos conocidos.
- 🤝 **Equipos:** referencia común para unificar cómo se usa la herramienta.

### 🔮 Futuro del proyecto

- 🔄 **Mantenimiento:** actualizar el catálogo cuando salgan nuevas versiones de Claude Code.
- 🪝 **Más contenido:** hooks, variables de entorno y ajustes de `settings.json`.
- 🌍 **Versión en inglés:** ampliar la audiencia.

### ⚠️ **Descargo de responsabilidad**

*Este proyecto es una referencia no oficial. La disponibilidad de cada comando depende de la versión, el plan, la plataforma y los plugins instalados.* **Escribe `/` en Claude Code para ver la lista exacta de tu entorno y consulta la documentación oficial ante cualquier duda.** Algunos ejemplos son ilustrativos y conviene probarlos antes de usarlos en proyectos reales.
